# Phase 4A Prototype Training Data

This directory is generated by `python scripts/train_models.py`.

- `flow_scenarios.jsonl` contains deterministic labeled feature vectors produced by driving the real bounded state managers and feature extractors with controlled lab scenarios.
- `dga_domains.csv` contains deterministic benign-like and algorithmically generated DGA-like domain examples.

This is synthetic/lab data for proving the training and inference pipeline. It is not a production corpus, and its labels or validation results must not be presented as real-world ground truth or detection accuracy. It is unrelated to runtime packet retention.
